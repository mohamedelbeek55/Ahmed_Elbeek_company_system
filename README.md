# نظام أحمد البيك للاستيراد والتصدير
## Ahmed Elbeek Convoy Management System

نظام رقمي مؤسسي متكامل صُمم خصيصاً لإدارة وتسيير قوافل الشاحنات التجارية بين مصر والمنافذ الحدودية (**ميناء رفح** و**ميناء العوجة**)، واحتساب النفقات التشغيلية (النولون، المبيت، التخليص الجمركي، والمصاريف الإضافية)، وإصدار وتوثيق بيانات الشحن الرسمية المعتمدة بتنسيق PDF قابل للتنزيل والمشاركة الفورية عبر WhatsApp.

---

## 🌟 الميزات التشغيلية الرئيسية

1. **إدارة قوافل الشاحنات ومواقع التحميل المعتمدة:**
   - إلزامية تحديد موقع التحميل عند الإنشاء: **ميناء رفح** أو **ميناء العوجة**.
   - تصفية فورية بحسب الميناء وحالة القافلة (جارية على الطريق / معتّقة ومكتملة).
   - تواريخ التحميل والتعتيق تعتمد **التاريخ فقط (Date-only)** بدون طلب ساعات أو دقائق، وفقاً لقواعد العمل المعتمدة.

2. **التعتيق والحساب الآلي الذكي (تعتيق بنقرة واحدة):**
   - احتساب الأيام المنقضية وليالي المبيت تقويمياً بشكل تلقائي: $\text{Nights} = \max(0, \text{UnloadDate} - \text{LoadDate})$.
   - احتساب تكلفة المبيت الإجمالية: $\text{Nights} \times \text{DailyRate} \times \text{TruckCount}$.
   - احتساب تكلفة النولون الإجمالية: $\text{FreightRate} \times \text{TruckCount}$.
   - المحافظة على رسوم التخليص الجمركي والمصاريف الإضافية كبنود مقطوعة مستقلة دون ضرب عشوائي.
   - حساب إجمالي المستحقات ومتوسط التكلفة للشاحنة الواحدة وتفقيط المبلغ باللغة العربية (ج.م).

3. **كشف وتنسيق السائقين المعتمد:**
   - كشف متكامل للشاحنات وفقاً لبيانات الوثيقة الرسمية: (م، السياسي / الوجهة، اسم السائق، الرقم القومي 14 رقماً، رقم لوحة السيارة، رقم لوحة المقطورة).
   - إمكانية استخراج كشف السائقين كملف PDF معتمد ومستقل.

4. **توليد مستندات الـ PDF المعتمدة ومشاركتها:**
   - توليد ملفات PDF حقيقية جاهزة للطباعة مقاس A4 مطابقة للهوية المؤسسية المعتمدة:
     - شعار الشركة الرسمي الدائري بالأعلى.
     - الخط الفاصل الأحمر المؤسسي (`#B51F2D`).
     - ترويسة الجداول الفحمية الداكنة (`#262626`) مع نصوص بيضاء وحدود رمادية فاتحة.
     - علامة مائية باهتة لشعار الشركة.
     - تذييل موحد بكل الصفحات يحمل أرقام التواصل المعتمدة: هاتف `01093313193` وبريد `elbeekb2b@gmail.com`.
   - تنزيل مباشر بنقرة واحدة، طباعة فورية، ومشاركة رسالة مهيأة بتفاصيل البيان عبر تطبيق WhatsApp.
   - أرشفة تلقائية لملفات المستندات في Supabase Storage مع ربطها بسجلات القوافل في قاعدة البيانات.

5. **إعدادات الشركة والمالك:**
   - إدارة البيانات التجارية المعتمدة (السجل التجاري، البطاقة الضريبية، العنوان).
   - تخصيص أرقام التواصل المعتمدة في تذييل الـ PDF.
   - تعديل القيم والتعريفات المالية الافتراضية.

## 🛠️ البنية التقنية (Tech Stack)

- **Frontend & App Framework:** Next.js 14 App Router (React 18 + TypeScript).
- **Styling:** Tailwind CSS مخصص بنظام التصميم الرسمي المستخرج من Google Stitch (خط Cairo، ألوان الشركة: Crimson Red `#B51F2D`, Charcoal `#262626`, Pale Red `#F7E6E8`).
- **Backend & Database:** Supabase PostgreSQL مع تفعيل Row Level Security (RLS) وسياسات الحماية.
- **Authentication:** Supabase Auth مع بوابة وصول خاصة للمالك (`ahmed.elbeek`).
- **Storage:** Supabase Storage (`statements` bucket) لحفظ ملفات الـ PDF.
- **PDF Engine:** jsPDF + html2canvas لدعم اللغة العربية وتنسيق RTL بدقة عالية.

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الاعتماديات:**
   ```bash
   npm install
   ```

2. **تشغيل الاختبارات الآلية:**
   ```bash
   npm test
   ```

3. **تشغيل بيئة التطوير:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. **بناء نسخة الإنتاج:**
   ```bash
   npm run build
   ```
